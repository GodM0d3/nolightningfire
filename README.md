# No Lightning Fire

A lightweight Fabric mod that prevents lightning strikes from starting fires in Minecraft, while preserving all other vanilla lightning mechanics.

## Features

- **Prevents lightning-generated fire:** Lightning strikes no longer create fire blocks.
- **Preserves vanilla behavior:** Lightning damage, mob transformations, lightning rods, copper oxidation removal, sounds, and visual effects remain unchanged.
- **Server-side only:** No installation required for players connecting to a modded server.
- **Singleplayer compatible:** Also works in singleplayer when installed on the client.
- **Lightweight:** Uses a single Mixin with no additional gameplay logic.
- **No configuration needed:** Works automatically after installation.

## Compatibility

| Requirement | Version |
|---|---|
| Minecraft | 26.3 |
| Mod Loader | Fabric |
| Java | 25 or newer |
| Environment | Client (singleplayer) / Dedicated Server |
